## If Cesium ion usage gets heavy

Your instruction (2026-10-08): ion stays the first choice; if its usage gets heavy, move to open-source data and tools in this order, one rung at a time, and record each switch as a dated line above.

1. **Imagery with no token:** OpenStreetMap standard tiles (already in the layer switch) or CARTO basemaps (Positron, Dark Matter; credit "OpenStreetMap contributors, CARTO"; you noted CC BY 3.0, confirm the current terms) loaded with Cesium's UrlTemplateImageryProvider.
